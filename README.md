# Micromouse Autonomous Maze Robot

## Overview
This project is an IEEE Micromouse robot designed to autonomously navigate and solve a maze. The goal is to build a compact embedded system that integrates sensing, motor control, and decision-making to efficiently explore unknown environments.

I contributed to both the hardware and firmware development, including schematic design, PCB layout, soldering, and ongoing embedded programming and testing.

---

## Features
- Autonomous maze navigation system
- IR-based wall detection
- Differential drive motor control
- Custom PCB design and assembly
- Embedded firmware for sensor processing and motion control

---

## Hardware Design
The system was designed in **EasyEDA**, including both schematic capture and PCB layout.

Key hardware components:
- Microcontroller-based control system
- Infrared (IR) sensors for wall detection
- Motor driver circuitry for dual DC motors
- Power regulation and distribution system
- Programming/debugging interfaces

The PCB was optimized for compact size, clean routing, and reliable signal integrity.

---

## PCB Fabrication & Assembly
After completing the design, the PCB was fabricated and fully assembled by hand.

Responsibilities:
- Schematic design and verification
- PCB layout and trace routing
- Footprint selection and validation
- Manual soldering of all components
- Hardware debugging and continuity testing
